## Идея решения

Сначала из графа удаляются все вершины без входящих или без исходящих дуг, так как они не лежат ни на одном цикле. Это позволяет уменьшить число кандидатов на попадание в X. Дальше используется жадный алгоритм - из графа выбирается вершина с максимальным произведением входящей и исходящей степени, причем степени считаются только по дугам внутри своей компоненты сильной связности. Затем выбранная вершина кладётся в X и удаляется, при этом каскадом удаляются вершины, оставшиеся без входящих или исходящих дуг, так как они больше не лежат на цикле. Для поиска компонент связности используется алгоритм Косарайю. После нескольких итераций выбора точек в X одна компонента связности может разбиться на несколько, и в результате степени будут не актуальны. Поэтому компоненты пересчитываются после каждых примерно 5% выборов. Затем идёт оптимизация ответа - вершины множества X проверяются с конца на предмет того, что они не лежит на цикле после возврата в граф. Проверка осуществляется обходом в глубину. Если вершина лежит на цикле, то она убирается из ответа и возвращается в граф. Остаток всегда ацикличен, поэтому ответ допустим на любом шаге.

Пока остается время, весь жадный алгоритм повторяется с рестартами: ключ жадности домножается на случайный коэффициент из [0.6, 1.4], и запоминается лучший найденный ответ. Первый запуск идёт без шума, поэтому результат не хуже обычной жадности.

## Инструкция по запуску

Требования: g++ с поддержкой C++17 (проверено на g++ 15.2.0, Ubuntu).

Сборка из дирректории задания:

В bash:
```
g++ -O2 -std=c++17 -o solution solution.cpp
```

Программа читает граф из stdin, а множество вершин печатает в stdout, по одной вершине в строке.

В bash:
```
./solution < input.gr > output.txt
```
